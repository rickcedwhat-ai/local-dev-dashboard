4 · How a click actually runs

Rules are data only. The menu shows each action's label; clicking sends POST /api/pr-action { projectId, pr, ruleId, actionId }. The server looks the action up in the saved rule (the browser never sends the command) and runs it with one of a few built-in handlers. No arbitrary shell from config.
