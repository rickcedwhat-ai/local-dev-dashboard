# UI mocks

Exploratory HTML for dashboard ideas. **Not** production UI.

## How to use

1. Open the live dashboard → **Mockups** (header).
2. Or open files under `/mocks/…` directly.

## Adding a mock

1. Add `public/mocks/your-mock.html`.
2. Add an entry to `catalog.json` (title + short desc).
3. Delete the file **and** catalog entry when the idea ships or is abandoned.

The dashboard Mockups modal reads `catalog.json` only — orphan HTML files won’t show up.
